# تحكم بالإيماءات (Gesture Control) — أندرويد

تطبيق يلتقط حركة يدك بالكاميرا الأمامية (MediaPipe Hand Landmarker) ويحوّلها إلى أوامر تحكم في الهاتف عبر خدمة إمكانية الوصول.

## التشغيل
1. افتح المجلد في **Android Studio** (Koala أو أحدث) وانتظر مزامنة Gradle.
2. وصّل هاتفاً (Android 8.0+) أو شغّل التطبيق مباشرة على الهاتف.
3. في التطبيق:
   - **الخطوة 1:** فعّل "تحكم بالإيماءات" من إعدادات إمكانية الوصول.
   - **الخطوة 2:** اضغط "تشغيل التحكم بالإيماءات" وامنح إذن الكاميرا.
4. أول تشغيل ينزّل نموذج اليد (~8 ميغابايت) ويحتاج إنترنت مرة واحدة فقط.

## الإيماءات
| الإيماءة | الأمر |
|---|---|
| ☝️ سبابة للأعلى (تثبيت ~0.4 ثانية، وتتكرر كل ~1.2 ثانية) | ريلز تالٍ (تمرير للأعلى) |
| 👇 سبابة للأسفل (نفس الشرط) | ريلز سابق (تمرير للأسفل) |
| ✊ قبضة (تثبيت ~1 ثانية) | الشاشة الرئيسية |
| ✌️ علامة النصر (تثبيت) | رجوع |
| 🖐 كف مفتوح (تثبيت) | التطبيقات الأخيرة |
| 👍 إبهام للأعلى (تثبيت) | نقرة في منتصف الشاشة |
| 🖐 كف مفتوح يتحرك لأعلى / لأسفل | تمرير للأسفل / للأعلى |
| 🖐 كف مفتوح يتحرك يميناً / يساراً | سحب لليمين / لليسار |

## الملفات المهمة
- `GestureEngine.kt` — تصنيف الإيماءات وكشف الحركة (عدّل الحدود في `companion object` لضبط الحساسية).
- `GestureService.kt` — خدمة أمامية: الكاميرا الأمامية + MediaPipe.
- `ControlAccessibilityService.kt` — تنفيذ الأوامر (رجوع، رئيسية، سحب، نقر).
- `MainActivity.kt` — الواجهة والأذونات.

## ملاحظات
- التحكم يعمل وأنت تستخدم تطبيقات أخرى لأن الخدمة تعمل في الخلفية، لكن أندرويد يُظهر أيقونة الكاميرا في الشريط طوال التشغيل.
- لضبط الحساسية: `HOLD_MS` (زمن التثبيت)، `SWIPE_DIST` (مسافة السحب)، `COOLDOWN_MS`.

## إدارة الإيماءات (من الشاشة الرئيسية)
القائمة تحت «الإيماءات» في الشاشة الرئيسية:
- **تعطيل/تفعيل** أي إيماءة بالمفتاح بجانبها (تشمل حركات الكف: أعلى/أسفل/يمين/يسار).
- **تغيير الأمر** المرتبط بها من القائمة المنسدلة، أو اختيار «بدون أمر».
- **إضافة إيماءة جديدة**: زر الإضافة ← اسم + أمر ← «تسجيل»، ثم عدّ تنازلي 3 ثوانٍ وثبّت يدك أمام الكاميرا (يجب أن يكون التحكم شغّالاً).
- **حذف** الإيماءات التي سجّلتها (المعلَّمة بـ ⭐).
- الإيماءات المسجّلة لها أولوية على المدمجة. لضبط الحساسية عدّل `CUSTOM_THRESHOLD` في `GestureConfig.kt` (أصغر = أدق).
- أي إيماءة مرتبطة بـ «سحب لأعلى/لأسفل» تتكرر طالما بقيت يدك على وضعها (مناسبة للريلز).

## وضع المؤشر (ماوس بالإصبع)
من الشاشة الرئيسية فعّل مفتاح **وضع المؤشر**:
- تظهر نقطة فوق أي تطبيق تتبع طرف **سبابتك** أمام الكاميرا الأمامية (أزرق = حر، أحمر = قرصة).
- **قرصة** الإبهام والسبابة هي «اللمس»: قرصة سريعة = ضغطة، قرصة مع تحريك = سحب مستمر (تمرير/تقليب)، قرصة مع تثبيت ثم فكّ = ضغطة طويلة.
- شريط **مساحة حركة يدك** يضبط الحساسية (يسار = حركة صغيرة تكفي).
- أثناء هذا الوضع تتوقف الإيماءات العادية؛ أطفئ المفتاح للرجوع لها.
- يلزم تثبيت الموبايل على حامل. للضبط عدّل ثوابت `PointerController` (`PINCH_PRESS`, `PINCH_RELEASE`, `LONG_MS`) والتنعيم في `OneEuro`.
